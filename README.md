# ♻️ Ecoponto Uberlândia
App web para celular que mostra os ecopontos de Uberlândia (MG) no mapa, encontra o mais próximo e traça rota.
## Publicar no GitHub Pages
1. Crie um repositório e envie estes arquivos.
2. Settings → Pages → Branch `main` → Save.
## Editar ecopontos
Altere `data.js`. As coordenadas atuais são aproximadas.
